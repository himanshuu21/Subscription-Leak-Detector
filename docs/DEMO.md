# Two-minute demo script

1. Sign in with a dedicated demo account (never a real user account).
2. Upload `sample.csv` and point out imported, credit, and invalid row counts.
3. Open the dashboard and show the six evidence-supported detections and the absence of Swiggy.
4. Mark one subscription “Cancel” and show projected annual savings.
5. Run `python scripts/evaluate.py` to show precision, recall, F1, false positives, and false negatives.
6. Close on the architecture diagram and GitHub Actions run.

Record this flow after deployment so the video shows the real public URL and current UI. Do not publish reusable production credentials; create a resettable, rate-limited demo account instead.
